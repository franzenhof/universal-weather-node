2 The node
PCB v2.0 · open source hardware

Universal Weather Node

Heltec WiFi LoRa 32 V4 (or V3) — ESP32-S3 + SX1262, OLED display
  • One LoRa chip, two jobs: LoRaWAN uplinks and 868 MHz reception of up to 32 wireless sensors in between (★ mine / hide the neighbour's)
  • Value sources: Auto (board first, then wireless 1–4 in Ecowitt's order), board, wireless or off — per value; calibration per sensor
  • Computed on the node: dew point, feels like, pressure tendency and trend, rain hour … year, sunshine, records, sun and moon, warnings
  • WMO wind: 3-s gusts, interval or 10-min values per output
  • Setup from the phone: setup wizard, web settings in 5 languages, firmware update in the browser, backup / restore, LoRaWAN downlinks

Minimal build for wireless sensors — no custom PCB

Heltec WiFi LoRa 32 V4 (or V3) + BME280 module on four wires (3V3, GND, 41, 42) + Bresser, TFA or Ecowitt sensors — same firmware, same outputs.

3 Outputs — independently, in parallel

LoRaWAN

ChirpStack · TTN

Kilometres of range without Wi-Fi. Compact binary format or CayenneLPP, decoder included — on to Grafana, ioBroker, Node-RED.

MQTT + Home Assistant

Wi-Fi · TLS

JSON with all values and every wireless sensor, Home Assistant auto-discovery, publish interval down to seconds.

Web dashboard + REST

in your LAN · offline

Live values, trend charts, wind rose, records, status page and built-in help — also as an app on the phone. /api/data for your own tools.

Weather networks

direct upload

AWEKAS, Weather Underground, Weathercloud, Wetternetzwerk.pro, Windy, openSenseMap, Met Office WOW and CWOP — with 10-min WMO wind values; plus your own HTTP uploads.

Alarms & notifications

push · MQTT · webhook

Rules such as “gust above 60 km/h” or “sensor silent” to ntfy, Pushover, Telegram, MQTT or a webhook — with minimum duration, priority and a test button.

Loxone & OLED

UDP · HTTP · on the board

Values pushed to a Loxone Miniserver; the board's own OLED shows the weather screens.

Everything runs on the ESP32-S3 — no PC, Raspberry Pi or cloud service in between · all transports at the same time · metric or imperial · open source
