Minimal wireless build — 4 wires, no custom PCB

Heltec V3 + BME280 + 868 MHz sensors

1

Flash

USB-C cable to the Heltec, flash the firmware once (pio run -t upload). Later updates over Wi-Fi (OTA). The same USB-C socket powers the node.

2

Wire

Four jumper wires: 3V3→VIN GND→GND 41→SDA 42→SCL. No soldering on the Heltec (pin headers), no resistors.

3

Configure

Portal / web settings: wind + rain sensor off, wireless sensors on with the matching sensor type, source temperature/humidity = Wireless 1.
